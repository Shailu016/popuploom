Last reviewed 6 November 2026. This page gives directories, newsletters and publications approved wording for PopupLoom. Use it to keep brand facts consistent. It does not claim awards, user counts, ratings or conversion results.

One line

PopupLoom is a free website popup builder with 45 templates, a visual editor, hosted embed code and lead capture.

Short (about 50 words)

PopupLoom is a free website popup builder for small shops, ecommerce stores and lead-generation sites. It includes 45 templates, six popup triggers, page and device targeting, a hosted install snippet, a lead inbox and CSV export. No credit card or trial timer is required; a free account is needed to save and install a popup.

Medium (about 100 words)

PopupLoom is a free website popup builder for site owners who can add custom HTML or JavaScript to their own website. The visual studio ships with 45 original templates and a blank canvas, plus page-load, delay, scroll-depth, scroll-to-element, click and desktop exit-intent triggers. Campaigns can target page paths with wildcards, enable desktop and phone separately, and use frequency rules to avoid repeat interruptions. A saved widget gives a two-line embed that loads a hosted configuration, so edits sync without replacing the snippet. Form responses appear in a lead inbox with CSV export and optional webhooks. There is no credit card step, trial timer or paid upgrade inside the product.

Long (about 200 words)

PopupLoom is an independent, free website popup builder operated by Shailu. It is designed for small businesses, ecommerce stores, quick-commerce storefronts, agencies and creators who want a focused popup tool without a monthly subscription. The studio includes a visual editor, 45 original templates, a blank canvas and content blocks for headings, text, images, video, countdowns, code chips, choices, calls to action and fine print.

Each widget uses one automatic trigger: page load, a timed delay, scroll depth, scroll to a CSS selector, a click on a CSS selector, or desktop exit intent. Page targeting supports include and exclude lists with wildcards. Desktop and phone can be enabled separately, and frequency rules range from every load to once ever. Saved widgets are hosted by PopupLoom and installed with a two-line snippet pasted before the closing body tag.

Forms can collect text, email, phone, number, date and URL responses. Leads appear in the owner's authenticated lead inbox, with CSV export and optional browser or signed server-side webhooks. PopupLoom does not read cart contents, send email or SMS, generate coupons, run A/B tests, attribute revenue or inject into native mobile apps. It does not guarantee conversions.
