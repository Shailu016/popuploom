Add a popup to Framer

Framer lets you add a script to the whole site or to a single page from its settings. This guide covers where to paste the two PopupLoom lines and how to confirm they run. It was checked against Framer's own Custom Code lesson, not tested on a live Framer site.

Check your plan first. Framer's Custom Code lesson does not say which plan includes the setting. If the Custom Code section is missing or locked in your project, check Framer's pricing page or your project's plan before assuming the steps below are wrong. This guide has not confirmed the plan requirement.

Add the snippet to the whole site

  1. Create and save a popup in the studio and copy its widget ID from the install code.
  2. In Framer, open Site Settings and find the Custom Code section.
  3. Choose the end-of-body location. Framer offers locations at the start and end of the head and the body, and its lesson says to use the placement a script's own instructions ask for. Check the exact labels in your settings.
  4. Paste both lines:
<div data-popuploom="YOUR_WIDGET_ID"></div>
<script src="https://popuploom.com/embed/1.2.0/popuploom.js"></script>

Replace YOUR_WIDGET_ID with your own ID, save the setting and publish the site.

Add it to one page only

Each page has its own settings with a Custom Code section. Use it when the popup belongs on a landing page and nowhere else. This is the simplest way to keep a popup off pages such as legal notices or a checkout link.

Try it on your own page

Open the Welcome Offer, Image Header template, replace the sample text with your own and preview it on desktop and mobile. Free, no credit card.

Publish before you test

Framer's lesson states that custom code does not load in the canvas preview. Publish the site, open the live address in a private window and check the popup there. If nothing appears, open the browser console and look for a blocked or failed script request.

Pages and targeting

GoalWhere to pastePopup URL rule
Every pageSite Settings, Custom CodeOptional
One landing pageThat page's Custom CodeOptional
Several pagesSite Settings, Custom CodeMatch the paths, for example /pricing*

Two layers: Framer decides where the widget loads, and the popup's own rule decides where it appears. If a popup never shows on a page, check both before changing the template.

Test checklist

  • Published site in a private window, popup appears once.
  • The pages you targeted show it and the others do not.
  • Mobile width works and the close button is easy to reach.
  • A test submission arrives in the lead inbox.
  • The browser console has no errors from the widget.

Removal

Delete the two lines from Custom Code and publish again. The saved popup stays in the studio.

Common questions

Does the popup show in Framer's canvas preview?

No. Framer's Custom Code lesson says custom code is not loaded in the canvas preview. Publish the site and test on the live address.

Do I need a paid Framer plan for Custom Code?

Framer's Custom Code lesson does not state a plan requirement, and this guide has not confirmed one. If the section is missing or locked in your project, check your plan on Framer's pricing page.

Can I put the popup on one page only?

Yes. Use that page's own Custom Code section, or paste it site-wide and limit it with the popup's URL rule.

Where in the page should the script go?

Use the placement the script's instructions ask for. For this widget the end of the body is the usual choice, so it does not block the page's own content.

Is there a limit on popup views?

PopupLoom does not cap pageviews or impressions. Your Framer plan has its own limits, which are separate; check them on Framer's side.
