Carrd adds custom code through an Embed element. This guide covers the setting that matters, the plan it needs and how to test the published page. It was checked against Carrd's own documentation, not tested on a live Carrd site.

Plan requirement. Carrd's documentation says the Embed element with custom code “Requires Pro Standard or higher.” On a free Carrd site you cannot add the two lines. Check your plan before you start.

Add the embed

  1. Create and save a popup in the studio and copy its widget ID from the install code.
  2. In the Carrd editor, add a new Embed element from the Add Element menu.
  3. Set Type to Code.
  4. Paste both lines into the Code field:
<div data-popuploom="YOUR_WIDGET_ID"></div>
<script src="https://popuploom.com/embed/1.2.0/popuploom.js"></script>
  1. Replace YOUR_WIDGET_ID with your own ID and give the embed a label such as “PopupLoom widget” so you can find it later.
  2. Set Style to Hidden and choose Body End as the location.
  3. Publish the site.

Hidden or inline

Carrd's documentation describes two styles. Inline puts the code exactly where the embed sits on the page. Hidden places it in one of three locations: the head, the top of the body or the end of the body. A popup does not need a visible spot on the page, so Hidden at the end of the body is the cleaner choice.

Publish before you test

Carrd's documentation notes that an embed shows nothing in the builder. Publish, open the live address in a private window and check the popup there. If nothing appears, open the browser console and look for a blocked or failed script request.

Test checklist

  • Published site in a private window, popup appears once.
  • Mobile width works and the close button is easy to reach.
  • A test submission arrives in the lead inbox.
  • The browser console has no errors from the widget.
  • The popup does not cover the page's own button before the visitor has read the page.

Removal

Delete the Embed element and publish again. The saved popup stays in the studio.

Common questions

Which Carrd plan do I need?

Carrd's documentation says the Embed element with custom code requires Pro Standard or higher. A free Carrd site cannot add the snippet.

Why can I not see the popup in the Carrd editor?

Carrd's documentation says an embed displays nothing in the builder. Publish the site and test on the live address.

Should I choose Inline or Hidden?

Hidden at Body End. A popup builds its own dialog, so it does not need a place in the page layout.

Can I run PopupLoom on more than one Carrd site?

Yes, add the embed to each site. Each popup has its own widget ID, so you can use the same one or a different popup per site.

Is there a limit on popup views?

PopupLoom does not cap pageviews or impressions. Your Carrd plan has its own limits, which are separate; check them on Carrd's side.
