Checked against Shopify's official theme-code documentation on 12 November 2026. This guide was not tested on a live Shopify store; themes, plans and checkout extensibility vary, so verify on a development or unpublished theme first.

You do not need a paid Shopify popup app to show a popup. If you can edit theme code, you can paste the two-line PopupLoom snippet into layout/theme.liquid and publish it with the theme you already pay for. No app install, no app subscription, no app block. The trade-off is that you manage one code snippet yourself, and the popup cannot read cart contents or appear inside checkout.

Choose an app if you need cart-value triggers, native discount logic, A/B testing or checkout messages. Choose the theme snippet if you want a free, lightweight popup for the storefront and you are comfortable editing one file.

Before you start

  • You need theme-code access for the store. Staff permissions and Shopify plans differ.
  • Duplicate the theme before editing. Shopify's theme-code documentation recommends duplicating a theme before deleting or changing files. A duplicate is a snapshot: later edits to one theme do not automatically sync to the other.
  • PopupLoom is installed as theme code, not as a Shopify app. There is no app block or checkout extension provided by PopupLoom.
  • Do not promise popups inside checkout. Checkout script support is restricted and depends on the store's plan and checkout extensibility. Test the actual checkout step separately; do not assume a theme popup carries into checkout.

Open it in the studio

Step 1: Save the popup and copy its code

Build and save the popup in the PopupLoom studio, then copy the two-line install pair from Publish. The full explanation is in the installation guide. Use your own saved widget id; do not use a preview id.

Step 2: Duplicate the theme

In Shopify admin, open Online Store → Themes. Duplicate the live theme, or create a development copy, and work there first. The duplicate is a separate snapshot; changes you make to one theme are not automatically copied to the live theme. When the duplicate is ready, publish it as the live theme. If the change is wrong, you can switch back to the previous theme without rebuilding the storefront.

Step 3: Edit theme.liquid

  1. Open Online Store → Themes.
  2. Open the theme actions menu and choose Edit code. Shopify's official guide describes this code editor.
  3. Find layout/theme.liquid. Most themes use it as the outer document layout.
  4. Paste the PopupLoom div and script immediately before the closing </body> tag.
  5. Save the file.
  6. Preview the unpublished theme and test the trigger on a published preview URL or a development store.

If your theme does not use layout/theme.liquid, use the layout file that contains the closing body tag. Do not place the script inside a product description, a section setting that escapes HTML, or a metafield that is rendered as text.

Step 4: Test the published storefront

  • Open a private window on the published domain, not the theme editor preview.
  • Confirm the script and widget div are in the page source.
  • Perform the real trigger and test one form response with fake data.
  • Check the lead inbox and the browser console.
  • Test mobile separately. Some themes change the footer or inject scripts only on certain templates.
  • If the change does not appear after publishing, confirm that the edited theme is the theme currently published as live (not merely a preview or a different duplicate). Inspect the published page source for the snippet, then request the page in a fresh private window. Shopify does not expose a generic theme/CDN purge control. If the published source still lacks the change, contact Shopify Support with the theme name and the file you edited.

Shopify-specific problems

  • The code appears as text. The setting or section escaped it. Use theme code, not a rich-text field.
  • The popup appears in the preview but not on the live domain. The theme may not be published, or the live theme is different from the one you edited.
  • It disappears on checkout. The checkout step has separate extensibility and script rules. Do not claim checkout coverage from a theme.liquid install.
  • A theme update affects the change. Shopify's theme-update guidance says code edits that do not conflict with the update are included with the updated theme; conflicting edits are not included and must be copied to the new version manually. Do not assume every update removes or preserves the snippet. Keep the exact snippet and its location, and compare the published source after an update.
  • Content Security Policy blocks the script. A theme or app may add a CSP. Allowlist the PopupLoom runtime origin or contact the theme/app provider; do not remove CSP globally.

Removing the popup

Remove the two lines from layout/theme.liquid, save the file, and restore the theme duplicate if anything else changed. Deleting the hosted widget separately removes its configuration and leads.

Shopify popup FAQ

Can I add a popup to Shopify without an app?

Yes, if you can edit theme code. Duplicate the theme, paste the widget div and script before </body> in layout/theme.liquid, and publish the duplicate. No app is installed and no app subscription is required.

Does it work at checkout?

Do not assume it does. Checkout has separate extensibility and script rules that depend on the store's plan. A theme install covers the storefront, not checkout. Test checkout separately and use a checkout extension if you need a message there.

Will a theme update remove it?

It depends. Shopify's guidance says non-conflicting code edits are included in the update; conflicting edits are not and must be copied manually. Keep the exact snippet and check the published source after an update.

Can it show cart value or specific products?

No. PopupLoom does not read cart contents, cart value, customer accounts or order history. It can target URLs and device type, and it can run on a cart page, but it cannot branch on what is inside the cart.

Is it free?

PopupLoom is free with no pageview cap or paid upgrade inside the product. A free account is required to save a widget and get install code. Shopify may charge for theme or plan features you use.
