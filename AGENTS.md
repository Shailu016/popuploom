# AGENTS.md

Operating rules for anyone (human or agent) changing this repo.

## Non-negotiable content rule: no competitor names

PopupLoom never names a competing popup, lead-capture or conversion-optimisation
product in public-facing copy. This was an explicit owner decision on 2026-11-16.

**Applies to every public surface:** page copy, headings, meta titles and
descriptions, Open Graph and Twitter tags, JSON-LD, image `alt` text, anchor text,
`llms.txt`, `llms-full.txt`, press materials, template pages, tool pages, FAQ
answers, and any content served to crawlers or agents.

**Also applies to shipped code and file names:** do not add new URLs, selectors or
labels containing a competitor brand. The only permitted exception is the existing
301 map in `server/index.js` and `worker/index.js`, which must keep the retired
`/alternatives/...` paths so old links resolve. Those strings are technical
redirects, not copy.

**Say the pattern, not the product:**

| Instead of | Write |
|---|---|
| "<Brand>'s free plan caps you at 5,000 pageviews" | "A 5,000-pageview free tier" |
| "<Brand> is better for WordPress" | "On WordPress, a self-hosted plugin is often the better fit" |
| "<Brand> alternative" | "Free popup builder with no pageview limits" |
| "Nine builders including <Brand>" | "Nine checks for any shortlist" |

**Allowed proper nouns:** PopupLoom itself; the platforms it installs on
(WordPress, Shopify, Webflow, Squarespace, Wix, and similar); integrations the
product actually supports or connects to (for example Mailchimp, Klaviyo, Zapier,
Google Analytics); standards bodies and protocols; and infrastructure vendors when
stating a factual deployment detail (for example Cloudflare, Google). None of these
may be used to imply a partnership, endorsement or certification.

**Enforcement:** `tests/regression.test.cjs` fails if any of the current competitor
names appear on the guarded public pages. When a new competitor is added to the
ban list, extend that array rather than writing a one-off check.

**Out of scope:** `docs/SEO_GROWTH_PLAN.md`, `docs/SEO_DEEP_RESEARCH_2026-11-16.md`
and `docs/SEO_OUTREACH.md` are historical internal records. They keep competitor
names on purpose so past decisions stay traceable, and each carries a header saying
so. Do not copy their wording into site content without rewriting it vendor-neutral.

## Other standing rules

- No invented rankings, traffic figures, review counts, certifications, customer
  logos or conversion benchmarks. Dated, source-linked facts only.
- Free-tier and pricing claims must come from the vendor's own page and carry a
  visible check date.
- Ads only on the allowlist in `shared/ad-pages.js`. Never on private, app, legal
  or contact surfaces. New pages ship ad-free until reviewed.
- Keep nonce + `strict-dynamic` CSP on ad pages; ad-free pages use hash-based CSP
  generated by `scripts/csp-hashes.js`. Never add `unsafe-inline` or `unsafe-eval`
  to `script-src`.
- Preserve auth, webhooks, D1, lead data and the legacy `/popforge.js` /
  `data-popforge` compatibility surface.
- Registration and password-reset responses stay generic to prevent account
  enumeration.

## Before you ship

```bash
node scripts/csp-hashes.js      # after any HTML edit
npm run sitemap:lastmod         # after adding or editing pages
npm test                        # regression
npm run test:cf                 # worker unit
npm run test:cf:integration     # full worker integration
```

Deploy with `npm run deploy:cf`, then submit with `npm run indexnow`.
