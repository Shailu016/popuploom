Start from a blank popup

How to add a popup template to your website

  1. Pick a template. Choose the job first (capture an email, make a sale, announce news), then a layout that fits your page.
  2. Make it yours. Open it in the studio and replace the sample text, colours and image. Set when it appears and how often.
  3. Preview on desktop and mobile. Check both sizes, and test the trigger on a real page before you rely on it.
  4. Install and measure. Save the popup, paste the two-line install code before the closing body tag, then read views and leads in your inbox.

Popup template questions

Are these popup templates free?

Yes. Every template is free to preview, edit and install, with no pageview cap and no trial. A free account is only needed to save a popup and get its install code.

Do I need to code to use a template?

No. Pick a template, change the words, colours, image and trigger in the studio, then paste a two-line snippet before the closing body tag of your site. WordPress, Shopify, Webflow, Squarespace and Wix each have a short guide.

Can I change a template completely?

Yes. A template is only a starting point. You can change every word, the colours, the image, the placement, the trigger, the frequency and which pages and devices it appears on, or start from a blank popup instead.

Where do the leads from a template go?

Responses land in your PopupLoom lead inbox, where you can export them as CSV. An optional signed webhook can forward them to another tool. Sending any follow-up email is up to you.

Are the offers, codes and countdowns in the previews real?

No. Every preview uses sample copy. Discounts, stock levels, prizes, deadlines and guarantees must be true and honored by the site owner, so replace the sample text with your own before you publish.

Which template should I start with?

Start from the job the popup has to do. Use an email signup popup to grow a list, an offer popup to move a visitor to checkout, an exit-intent popup to catch someone leaving on desktop, and an announcement bar for one line of news.
