Free referral popup template

By Shailu, founder of PopupLoom Published 17 November 2026 Last updated 17 November 2026 Template checked 17 November 2026

A referral popup gives an existing customer a code to share and a reason to share it. The Refer a Friend template is a bottom-right slide-in with a short offer, a copyable code and a share button. It is a prompt and a delivery surface; the referral program itself lives in your store, membership system or referral platform.

This page covers the mechanics the popup can and cannot handle, the terms to publish before you show it, the frequency that keeps it from feeling like a demand, and how to measure a program honestly. It is one of the engagement templates.

The code is not created or validated here. PopupLoom displays the text you enter in the studio. It does not issue unique codes, check whether a code was used, stop self-referral or decide who qualifies for a reward.

What this template is for

The ask is simple: share a code with someone who would use the product. The layout keeps the code visible and copyable, so the customer does not have to remember it or hunt through an account page.

  • A two-sided offer where both the referrer and the friend receive something.
  • A single public code for a small store that handles rewards manually.
  • A member perk tied to an existing loyalty or account program.
  • A launch referral where the reward is a credit rather than cash.

It is not a fraud system. If the reward has real value, expect duplicate accounts, self-referral and code sharing beyond the intended audience. Those controls belong in the platform that issues and redeems the reward.

The terms to publish first

Write the rules before the popup, not after the first complaint. A referral program without terms is a promise the support inbox has to improvise.

  • Who may refer: new customers only, existing customers, or a specific tier.
  • Who may be referred: new customers only, or anyone who has not ordered in a set period.
  • What each side gets: a fixed amount, a percentage, a credit, or a free month.
  • When it is paid: on signup, on first order, or after the return window closes.
  • Limits: one reward per customer, a cap per month, no self-referral, no stacking with other codes.
  • Expiry and changes: when the code stops working and how changes are announced.

Link the full terms from the popup. If the offer is not available in a jurisdiction, say so rather than letting the code fail at checkout.

Use it when

  • The customer has completed at least one order or meaningful action.
  • The reward is funded and the terms are written down.
  • Your store can attribute the code to the referrer, even manually.
  • You can fulfill the reward without asking the customer to chase it.

Do not show it on the first page view, before checkout, or to a visitor who has not yet experienced the product. A referral ask is a request for advocacy; it needs something to advocate.

Copy you can adapt

Badge: Give [X], get [Y]

Headline: Share the code, both sides win

Body: Send this code to a friend. They save [X] on their first order and you get [Y] after it ships.

Code: FRIEND-10

Small print: New customers only. One use per friend. Reward is issued after the return window. Full terms.

Replace every bracket with a real number and a real condition. “Give $10, get $10” is a promise; if the reward is store credit that expires in 30 days, say that in the same panel. The copy generator can produce other structures, but the terms are yours to write.

Set it up

  1. Open the Refer a Friend template in the studio.
  2. Enter the real code and the exact terms in the small print.
  3. Set the trigger to Scroll depth at 75% and the frequency to once per week.
  4. Limit the URL rules to account, thank-you or member pages. Do not run it site-wide on the first visit.
  5. Save, publish and paste the install snippet using the installation guide.
  6. Test the code in your store before the popup goes live, including the reward path.
  7. Add the referral terms to a stable page and link that page from the panel.

If you need to collect the referrer's email

Turn the form on and add one email field. That changes the job: the code is now sent rather than shown, so the success message must say when it will arrive and who it will come from. It also means you are collecting personal data, so name the purpose and the retention period in your privacy notice.

Do not ask for the friend's email in the popup. Sharing someone else's address is a consent problem, and the customer may not have permission to give it. Let the customer forward the code themselves.

What to measure

  • Code redemptions in your store, not popup impressions.
  • New customers acquired versus existing customers using the code.
  • Reward cost per acquired customer, including credit that is never used.
  • Self-referral and duplicate-account rate, if the reward is worth gaming.
  • Share rate, if your platform can report it. PopupLoom cannot.

A high redemption count with no new customers is a discount, not a referral program. Measure the acquisition, not the clicks.

Common mistakes

  • Promising a unique code the popup cannot generate.
  • Showing a public code and calling it personal.
  • Launching without terms for eligibility, expiry or self-referral.
  • Asking for a referral before the customer has used the product.
  • Paying the reward on signup and then losing money when the order is returned.
  • Asking for the friend's email address.

Common questions

Can PopupLoom create a unique referral code for each customer?

No. The template displays a code you paste into the studio. Unique codes and attribution belong to your store, referral platform or membership system.

Can PopupLoom tell me who referred whom?

No. It records that the popup was shown and whether a form was submitted; it does not read order data, customer identity or referral source. Use your store's referral or coupon reporting for attribution.

Should the referral popup ask for an email?

Only if you need to send the code or track the request. A share-code layout works without a form. If you add a field, say who will email and what the address will be used for.

How often should a referral prompt appear?

Once a week at most, and only after the visitor has had a chance to use the product. A referral ask before the first purchase is a request for trust the visitor has not been given a reason to extend.
