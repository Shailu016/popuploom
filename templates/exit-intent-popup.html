An exit-intent popup appears when a desktop visitor moves the cursor out through the top of the page. It is the last moment before a visit ends, which makes it a reasonable place for a reminder or a real last-chance offer. It is not a page-load popup, and it does not work on touch screens.

The Don't Leave Empty template uses a fullscreen layout, one clear offer and a copyable code field. It is deliberately simple: at the exit moment, a visitor should understand the offer in one glance.

Use the Don't Leave Empty template See all exit intent templates

Why this template works

  • The fullscreen layout removes competing page elements at the decision moment.
  • A single code field is easier to use than a multi-field form when the visitor is already leaving.
  • The copy can be changed to a reminder, a first-order code or a content upgrade.
  • It is desktop-only, so it does not interrupt mobile readers with an event the device cannot detect.

Use it when

  • A visitor is leaving a product or content page and you have a real last-chance offer.
  • You want to remind a visitor about a saved cart or a guide they have not downloaded.
  • You can exclude checkout, payment and legal pages from targeting.
  • You can honor the code, deadline or shipping terms the popup shows.

Set it up

  1. Open the Don't Leave Empty template.
  2. Set the trigger to Exit intent and choose once-per-day or once-ever frequency.
  3. Exclude checkout, payment and legal pages in page targeting unless this is specifically a cart rescue.
  4. Replace the sample code, deadline and terms with a real offer you can honor.
  5. Save the popup, copy the install code from Publish, and add it to your site.
  6. Test in a private desktop window by moving the cursor out through the top edge, not by switching tabs.

What to measure

  • Submit rate, not total popup views.
  • Code redemption in the store, if the offer includes a code.
  • Close rate, which shows whether the offer or timing is wrong.
  • Complaint rate on repeat visits.

Common mistakes

  • Trying to fire exit intent on mobile; touch devices have no cursor and no dependable exit event.
  • Showing the same popup on every page to the same visitor.
  • Blocking the checkout or cancellation flow.
  • Using a fake deadline or a code that was never tested.

Common questions

Is this exit-intent template free?

Yes. The template is free to edit and install. A free PopupLoom account is required to save it and get the install code; there is no pageview cap.

Does exit intent work on mobile?

No. Touch devices have no cursor and no dependable leaving event. PopupLoom disables exit intent on mobile by design; use a delay or scroll trigger for phone visitors.

Why isn't the popup firing?

Exit intent only fires when the pointer leaves through the top of the viewport. Switching tabs, moving to a second monitor or leaving through the side does not count. Check frequency, page targeting and the console too.

Can I use this on Shopify or WordPress?

Yes where the theme or a code block allows custom HTML or JavaScript. See the Shopify and WordPress guides for placement and caching caveats.

Can I change the design?

Yes. The studio lets you change the copy, image, colors, trigger, page targeting, devices and frequency before saving.
