Free Black Friday popup template with countdown

By Shailu, founder of PopupLoom Published 16 November 2026 Last updated 16 November 2026 Template checked 16 November 2026

A Black Friday popup has one job: make the offer and the end date impossible to misread. This template uses a countdown, a single code and a button that leads to the sale. The design is deliberately loud; the copy has to stay literal, because a seasonal campaign is where invented urgency does the most damage.

Two rules decide whether the page works. The deadline must be real, and the code must work on the products the popup implies. Everything else — the animation, the colour, the border — is decoration around those two facts.

What this template is for

  • One campaign. Black Friday, Cyber Monday or a single flash window, not a season-long banner.
  • One code. The same code in the popup, the banner and the checkout, with the same conditions.
  • One end date. A date and time the visitor can verify, displayed in their timezone or clearly labelled.
  • A real destination. The button goes to the discounted collection, not the homepage.

Use it when

  • The sale has started and the code is live.
  • The discount applies to enough of the catalogue that the popup is not a bait line.
  • You can turn it off when the window closes.
  • You are not already running a second seasonal overlay on the same page.

Do not publish it a week early with a countdown to a sale that has not started, and do not leave it up after the code expires. Both are the same failure: the page promises something the checkout will refuse.

Copy you can adapt

Badge: BLACK FRIDAY

Headline: [X]% off until [DATE]

Subheadline: Use code [CODE] at checkout. Applies to [WHAT IT COVERS].

Button: Shop the sale

Small print: Ends [DATE, TIME, TIMEZONE]. Cannot be combined with other codes.

Name the exclusions in the small print. “Sitewide” is a promise that a single excluded brand can break, and the support message that follows costs more than the extra clicks.

Set it up

  1. Open the Black Friday Fortress template in the studio.
  2. Replace the percentage, code, date and exclusions. Check that the countdown points at the same end date.
  3. Set the trigger to a 10–20 second timer, or exit intent if the page is content-heavy.
  4. Add the URL rule and exclude checkout.
  5. Set the frequency to once per day.
  6. Publish and install the snippet before the sale starts, then test the code in checkout.
  7. Turn the popup off when the window closes, and remove the code from the store.

What to measure

  • Code redemptions against the number of popup impressions, if you track them.
  • Margin after discount, not revenue alone.
  • Support questions about exclusions or expiry, which usually mean the small print is unclear.
  • Post-sale behaviour: whether discounted buyers return at full price.

Common mistakes

  • A countdown that resets on reload or is measured from the visitor's first visit rather than the sale end.
  • Running Black Friday and Cyber Monday overlays at the same time.
  • Leaving the popup live after the code expires.
  • Discounting the whole catalogue when the margin only supports a category.
  • Using “sitewide” while excluding sale items, gift cards or bundles.

No scheduler, by design. PopupLoom has no date-based scheduling. You publish at the start and switch it off at the end. If you need automatic start and stop, that is a reason to use a campaign platform instead; the buying checklist explains how to evaluate that requirement.

Common questions

Does the countdown reset when the page reloads?

It should count toward the end date you configure, not restart on every load. Test it in a private window and after a reload. If it resets, do not present it as a real deadline; a timer that restarts teaches visitors to distrust every timer on the site.

Can I schedule the popup to start and stop automatically?

PopupLoom does not include a date scheduler. Publish when the sale starts and turn the popup off when it ends, or use the URL rule to limit where it appears. Leaving an expired code live is worse than missing the first hour.

Should Black Friday and Cyber Monday use the same popup?

Use one offer at a time. Stacking two seasonal popups on the same page splits attention and makes the discount look arbitrary. Change the copy and the end date between events rather than running both.

What should the discount be?

Whatever the margin can support. This template does not recommend a percentage. A discount that loses money on every order is not a campaign; check the unit economics before publishing the code.
