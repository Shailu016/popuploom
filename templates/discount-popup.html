Free discount popup template

By Shailu, founder of PopupLoom · Last updated 16 November 2026

Free to edit and install. No pageview cap, no trial and no credit card. Template behavior checked on 14 November 2026.

A discount popup works when the offer is real and the deadline is true. The 48-Hour Drop template combines a product image, a countdown layout and a copyable code field. It is designed for a short promotion, not for permanent urgency.

The template is a starting point. Replace the sample product art, code and deadline with your own. PopupLoom does not generate or validate coupon codes; you create the code in your store and paste it into the popup.

Why this template works

  • The countdown layout makes the end of the offer visible without a wall of text.
  • A copyable code field removes the step of retyping a code from a screenshot.
  • The product image gives the offer context, which is useful for a specific drop.
  • The layout is compact enough for a modal on desktop and a smaller card on mobile.

Use it when

  • You have a real 48-hour or weekend promotion with a tested code.
  • You are launching a product drop with a clear start and end time.
  • You want a first-order code with a stated expiry.
  • You can exclude checkout and payment pages from targeting.

Set it up

  1. Open the 48-Hour Drop template.
  2. Set the real start and end date, including the timezone.
  3. Create and test the discount code in your store before pasting it into the popup.
  4. Exclude checkout, payment and legal pages from page targeting.
  5. Choose a frequency that matches the promotion; once per day is usually enough.
  6. Save, copy the install code, add it to your site, and test the code at checkout.

What to measure

  • Code redemption, not just popup submissions.
  • Revenue per visitor during the campaign versus a normal week.
  • Close rate, which shows whether the offer or timing is wrong.
  • Refund and cancellation rate after the promotion.

Common mistakes

  • Resetting a countdown to fake urgency.
  • Leaving an expired code in the popup.
  • Showing a discount over the checkout or payment step.
  • Publishing a code that was never tested in the store.

Common questions

Is the countdown real?

The countdown is a display layout. You set the end date and are responsible for honoring it. PopupLoom does not reset it or validate the deadline.

Does the template create the discount code?

No. Create the code in your store platform and paste the real code into the popup. PopupLoom does not generate, validate or sync coupons.

Can I use it on Shopify?

Yes where the theme or an app allows custom HTML or JavaScript. The Shopify guide covers theme-code and app-embed options.

Can I show a low-stock message?

Only if the stock number is accurate. The template includes a message you must verify and update; it does not read inventory.

Is the template free?

Yes, with no pageview cap. A free account is required to save and install.
