The install code

Sign in, save a popup, then copy its install code from My popups. Paste this pair anywhere before </body> — the id in the div is yours:

<!-- PopupLoom install. Paste before </body> --> <div data-popuploom="wan_your_widget_id"></div> <script src="https://popuploom.com/popuploom.js"></script>
How it stays in sync. The snippet carries only your widget id. Visitors' browsers fetch the live config, so editing or republishing in the studio updates every installed copy without touching the site again. Installing requires a free account: guests can design and preview, but the install code is issued only for popups saved to your account.
Coming from the old PopForge domain? Guest drafts made before the move live in that browser's storage for the old site. Open the draft recovery page, download the backup file, then import it here from My popups. Sign in on this domain to reach account-owned popups; browser drafts do not transfer automatically.
Platform note. Some builders trap widgets inside an iframe (Wix editor previews, Canva, Google Sites), which can box fixed widgets in. Install into the page body where the platform allows custom code. WordPress HTML blocks, Shopify theme code, Webflow embeds and static hosts usually work, but plan limits, script filters, CSP and caching vary — check the installation guides and test the published page.

Website popup builder: common questions

Use PopupLoom to create email signup forms, discount offers, announcements, age gates and other website popups. Explore all 45 popup templates or read the website installation guide.

What is PopupLoom?

PopupLoom is a free website popup builder with a visual editor, 45 templates, saved designs, website embed code and lead capture.

Do I need an account?

You can design and preview popups as a guest. Create an account to save popups online and get installation code. Guest drafts are stored in your browser.

How do I add a popup to my website?

Save your design, open Publish in the studio, and copy the installation code. Paste the widget div and script before the closing body tag of your website.

Can I use PopupLoom with WordPress, Shopify or Webflow?

You can install the embed where your platform permits custom HTML or theme code. WordPress Custom HTML, Shopify theme code and Webflow embeds are options, depending on your plan and permissions. Popups placed inside an iframe cannot extend outside that iframe.

What popup triggers are available?

Choose a page-load, delay, scroll-depth, scroll-to-element, click or desktop exit-intent trigger. Configure page targeting, device settings and frequency rules for each popup.

Where are captured leads stored?

Responses submitted through installed hosted popups are stored in the PopupLoom database and associated with your saved widget. Your account controls access to your widget data. Optional client-side webhook URLs are visible to website visitors and must not contain private credentials.

Does PopupLoom guarantee better conversions?

No. Results depend on your audience, offer, placement and timing. Test designs on your website and respect visitor preferences.
