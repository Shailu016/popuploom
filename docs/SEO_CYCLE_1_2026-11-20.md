## Site health (own audit, 2026-11-20)

63 sitemap URLs, all 200. No title or description outside length bounds, one H1 per page, no missing alt text, structured data on every page. Only `/contact.html` is under 300 words, and it is a contact surface, so it stays short.

## Decisions

- **No title or description rewrites this cycle.** Every page that appears in search already has a specific title and description in range. With fewer than 30 impressions per page, a CTR change cannot be told from noise.
- **Overlap to review:** `/guides/wordpress-popup.html` and `/guides/wordpress-popup-without-plugin.html` target the same intent. Only the first appears in Search Console. Decide on consolidation (one page, 301 from the other) after the next review, when there is enough data to pick the winner. Consolidating needs a redirect entry in both `server/index.js` and `worker/index.js`.
- **Internal links:** the WordPress and email guides each have 23-24 internal links, so no orphan risk.
