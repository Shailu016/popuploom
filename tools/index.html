Free popup tools that run in your browser

By Shailu016, founder of PopupLoom Published 17 November 2026 Last updated 20 November 2026

What these are. Four working tools for the decisions around a website popup: whether it is worth running, what it should say, and how to trigger it. Every one runs entirely in the page you are reading. No account, no upload, no queue.

What they are not. They are not benchmarks. None of them knows your audience, your traffic quality or your results, and none publishes a conversion rate for you to aim at. The numbers a tool shows are the numbers you typed in.

Most popup advice jumps straight to design. The expensive mistakes happen earlier: an offer that cannot pay for the traffic it needs, a button that does not say what happens next, or a trigger that fires on phones where it cannot work. These six tools sit in front of those mistakes, and they are deliberately small.

Calculator

Popup ROI calculator

Enter your monthly visitors, how many times a visitor sees the popup, an expected conversion rate, what a signup is worth to you and any tool cost. It returns monthly displays, monthly signups, annual value, the break-even conversion rate and how quickly a pageview cap would be consumed.

  • Best for: deciding whether an offer can carry its own cost before you design anything.
  • Worth knowing: break-even is the number to watch. If your honest conversion estimate sits below it, the offer needs to change, not the design.
  • Limit: it is a model, not a forecast. It cannot see your traffic quality, and a flattering input produces a flattering output.
Open the ROI calculator

Copy generator

Popup copy generator

Choose an industry, a goal and a tone, and it assembles twelve complete sets: badge, headline, subheadline, button label and disclaimer. The matrix is fixed, so the same three choices always produce the same twelve sets and you can compare two directions fairly.

  • Best for: getting from a blank field to twelve defensible drafts in a minute.
  • Worth knowing: the placeholders are literal. [X], [DATE] and [CODE] must be replaced before publishing.
  • Limit: these are structural patterns, not tested winners. Nothing here knows your brand voice or your margins.
Open the copy generator

Reference

Popup copy swipe file

Twenty-four patterns grouped by the job they do: welcome offers, email signups, exit intent, restocks, announcements, reviews, events and feedback. Each pattern names the situation it fits, the structure to keep and the wording that usually weakens it. Available as a page and as a plain-text download.

  • Best for: when you know the message but not the shape of the sentence.
  • Worth knowing: the avoid-list is the useful half. Most weak popup copy fails on a claim the site cannot honour.
  • Limit: a pattern is not a strategy. It will not tell you which offer your audience wants.
Open the copy swipe file

Code generator

Exit-intent code generator

Set a sensitivity threshold, a delay and a cooldown, then copy a zero-dependency snippet that opens your own markup when the pointer leaves the top of the viewport. It checks for a fine pointer first, so it does not run on touch screens where the gesture does not exist.

  • Best for: sites that need the trigger without loading a popup product.
  • Worth knowing: the snippet triggers only. It does not render, store, frequency-cap or report anything — you supply the markup and the policy.
  • Limit: desktop only, and testable only on a real pointer device. Mobile exit intent is not a thing this can do.
Open the exit-intent generator

Code generator

Popup HTML code generator

Write a zero-dependency popup with your own headline, text, button link, colour, delay and cooldown, then copy it into any site that allows a script. The dialog is built from DOM nodes and closes with a button, the backdrop or Escape.

  • Best for: static sites and theme footers that need one simple popup without installing anything.
  • Worth knowing: the button is a link. There is no email field, page targeting or reporting.
  • Limit: a centred popup shortly after load is the pattern phones handle worst, so keep the delay and the frequency conservative.
Open the popup HTML generator

Code generator

Sticky announcement bar generator

Write a one-line bar pinned to the top or bottom of the page, with your message, an optional link, your colours and an optional dismiss button that remembers the choice for the days you set.

  • Best for: shipping cut-offs, sale end dates and short notices.
  • Worth knowing: the bar sits over the page edge and does not push content down, so check it against your own header.
  • Limit: no schedule, no page rules and no reporting. Remove it yourself when the message expires.

What these tools will not tell you

  • A conversion rate to aim at. Popup response depends on the offer, the audience, the traffic source, the trigger and the page. Any single number presented as a target is a guess dressed as a benchmark.
  • Which design is better. They produce structure and arithmetic, not a comparison. That requires your own traffic and one change at a time.
  • Whether your claims are legal. Discount wording, consent language and age gates have jurisdiction-specific rules. The tools keep the copy literal; compliance stays with you.
  • What happens after a signup. PopupLoom saves responses to your lead inbox and can forward them to your own webhook. It does not send marketing email, SMS or files.

How the tools work

All six are static pages with a small amount of first-party JavaScript. The calculator and the two generators compute in the browser from a fixed matrix or from your inputs; they make no network requests of their own. The swipe file is plain content. Nothing is submitted, so there is no server-side record of what you typed, and no account is needed to use any of it.

The popup product these tools support is separate. If you want a hosted popup with triggers, templates, a lead inbox and webhook delivery already built, that is the studio, and its limits are documented in the FAQ and on the free-tier page.

A note on the numbers. The ROI calculator asks for a conversion rate because you cannot model revenue without one. It does not supply a default and it does not endorse the figure you enter. The same caution applies to the copy tools: a pattern that reads well is not evidence that it performs well.

Common questions

Are these popup tools free?

Yes. All six are static browser pages with no account, no trial and no usage counter. The tools themselves are not metered; the popup product they support has separate limits, described on the free-tier page.

Do the tools send my numbers anywhere?

No. The calculator and both generators run in the page using JavaScript and make no network requests of their own. Nothing you type or select is transmitted, stored or added to an account.

Which tool should I use first?

Start with the ROI calculator if you are deciding whether a popup is worth running at your traffic. Use the copy generator or the swipe file once the offer exists and you need wording. Use the exit-intent generator only if you are writing your own trigger code.

Are the copy examples tested winners?

No. The swipe file and the generator produce structural patterns built from a job, goal and tone. They have not been tested on your traffic and no conversion rate is claimed for any of them.

Do the tools work on a phone?

The calculator, the copy generator and the swipe file work on any modern phone browser. The exit-intent snippet is desktop only by design: it listens for the pointer leaving the viewport, which touch screens do not produce. PopupLoom's own exit-intent trigger has the same desktop-only limit.

Can I use the generated copy or code in a commercial project?

Yes, the output is yours to use. You remain responsible for what it claims: replace every placeholder, make discounts and deadlines literal, and check that the code you paste is permitted by the site you paste it into. The exit-intent snippet is offered as-is, without warranty.
